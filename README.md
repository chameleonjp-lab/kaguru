# カグル（kaguru）

家具の依頼を受け、木材の木目と仕上げを整えて納品するブラウザゲームです。椅子・テーブル・棚に合う素材を選び、研磨・着色・連続化を進め、完成した木目を3D家具で確かめます。画面では「GRAIN LAB」と表示されます。

## 何を目指すゲーム？

依頼ごとに指定された材種と品質を満たすことが目標です。木目のつながり、仕上げ、材種と装備の相性を改善し、より高い納品スコアを目指します。レシピを達成すると仕上げ油や道具が解放され、以後の加工を補助します。

## はじめての遊び方

1. 白い家具と依頼内容を確認し、「依頼を受諾する」を選びます。
2. 指定の木材を選び、表示される専用レシピの順に「研磨」「着色」「連続化」を実行します。
3. 品質が足りない項目は案内を見て調整します。「戻す」「やり直す」で加工を修正できます。
4. 「完成家具を最終確認する」で仕上がりを見ます。赤い警告があれば作業に戻って改善します。
5. 条件を満たしたら「納品を確定する」。結果と報酬を確認し、次の依頼へ進みます。

操作は画面のボタンをクリックまたはタップします。家具の確認ではドラッグで回転、PCではホイール、スマホでは二本指で拡大縮小できます。加工の取り消し・やり直しには Ctrl+Z / Ctrl+Y も使えます。

## 起動方法と公開状況

このREADMEでは動作確認済みの公開URLを案内していません。ソースを手元で試す場合は、Node.js と package.json 指定の pnpm を用意して次を実行し、表示された開発サーバーのURLを開きます。

```sh
pnpm install
pnpm dev
```

`pnpm check` は型検査、`pnpm build` はビルドです。この説明の追加によって公開・配備や実機検証を行ったものではありません。
